機能

待ちがひと目でわかる

全セッションの状態を一覧で確認。動いているもの、確認待ち、完了済みがひと目でわかります。

待ちの理由もわかる

承認が要るだけなのか、プランをじっくり見る必要があるのか、選択肢から選ぶのか。ステータスドット自体が教えてくれるので、ジャンプする前に心構えができます。

必要なときだけ表示

確認が必要な瞬間に自動で現れ、全て解消すると自動で消えます。

1クリックでターミナルへ

行をクリックするとそのセッションへ即ジャンプ。iTerm2 は該当ペイン、Terminal / Ghostty は該当タブ、IDE はプロジェクトウィンドウまで移動します。

キーボードで全操作

⌥ Space（変更可能）でウィンドウをトグル。セッション移動もターミナルジャンプもキーボードで完結。

IDEにも対応

Android Studio・VS Code・Cursor などの統合ターミナルから起動したセッションも一覧に表示。クリックでそのプロジェクトのウィンドウへ遷移できます。

メニューバーで状態表示

ウィンドウを開かなくても、メニューバーのアイコンが状態別の件数を色付きドットで表示。確認待ちが何件あるか常に把握できます。

表示モードを選べる

初回セットアップでシンプル／猫部屋を選択。設定からいつでも切り替えられます。一覧・ショートカット・ワンクリックジャンプはどちらのモードでも同じです。

おまけ：癒しの猫部屋モード

Claude の作業を見守る時間に、ちょっとした癒しを。猫部屋モードに切り替えると、同じセッション一覧の下でピクセルの猫たちが暮らします。

ピクセルアートの猫部屋

セッション状態に連動して猫が動き、時刻で昼と夜の景色が変わります。

猫の鳴き声で通知

セッションに確認が必要になると猫の鳴き声でお知らせ。画面を見ていなくても見逃しません。音が気になる場合は設定からいつでもミュートでき、通知センターは使いません。鳴き声はシンプルモードでも使えます。

よくあるご質問
  • 動作環境は何ですか？

    macOS 13 Ventura 以降（Apple Silicon・Intel 両対応）が必要です。Claude Code（claude CLI）のインストールも必要です。

  • 対応しているターミナル・IDE は？

    セッション検出は Claude Code の hook を使うため、どのターミナルでも動作します。異なるのは、クリックでどこまで正確にジャンプできるかです。

    ホスト ジャンプ精度
    iTerm2 ペイン
    Terminal タブ
    Ghostty 1.3+ タブ / ペイン
    VS Code · Cursor · Zed ウィンドウ
    Android Studio · JetBrains IDEs ウィンドウ
    Warp · kitty · WezTerm · Alacritty アプリ
    tmux 検出のみ

    tmux のセッションは検出・追跡されますが、ジャンプは現状非対応です。

  • 必要な macOS の権限は？

    セッション検出に特別な権限は不要です。ジャンプはジャンプ先により異なります。iTerm2 / Terminal / Ghostty はオートメーション権限（初回ジャンプ時のダイアログで「許可」を押すだけ）、Android Studio などの IDE はアクセシビリティ権限が必要で、VS Code 系・Warp・kitty・WezTerm・Alacritty は権限不要です。

  • セッションはどうやって検出されますか？

    AgentManager は Claude Code の hook を使ってセッションを検出します。初回オンボーディング時に hook が ~/.claude/settings.json へ自動で登録されるため（書き込み前に .bak バックアップを作成）、それ以降は claude を起動するだけで一覧に表示されます。追加の設定は不要です。サブエージェント実行中のセッションは、最後の1つが終わるまで「処理中」のまま表示されます。

  • セッションデータはどこかに送信されますか？

    セッションの内容（プロンプト・パス・セッション名）が Mac の外に出ることはありません。送信されるのは匿名のクラッシュレポートと利用統計のみで、そこにもパス・セッション名・ライセンスキーは含まれません。

  • 本当に無料で使えますか？アップグレードすると何が変わりますか？

    はい — 無料プランに期間制限はなく、全機能を利用できます。違いは同時に表示できるセッション数だけで、無料プランは 2 件まで、アップグレードすると無制限になります。料金は月額 $4.99 または年額 $48（約2ヶ月分お得）。ダウンロードするだけで使い始められます。

  • 1ライセンスで何台の Mac で使えますか？

    台数の上限はありません。お手持ちの Mac すべてにインストールしてご利用いただけます。有効化は端末ごとに行われ、設定 → ライセンスの「この端末を解除」でいつでも解除できます。

  • アップデートはどう届きますか？アプリは安全ですか？

    アップデートはアプリ内で自動的に届きます。すべての更新はインストール前に署名検証され、アプリ本体も Apple の公証（ノータリゼーション）を受けています。

  • シンプルモードと猫部屋モードは後から切り替えられますか？

    はい。初回セットアップで選んだ表示モードは、設定からいつでも変更できます。機能は両モードで共通です。
