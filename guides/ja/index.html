Claude Code ガイド

Claude Code を使いこなす人が必ずぶつかる 2 つの課題への実践的な解説集です。複数セッションを 衝突させずに同時実行する方法と、そのどれかが対応を求めている瞬間を確実に把握する方法。

セッションを並行実行する

  • git worktree で Claude Code を並行実行する

    1 クローン・1 ブランチ 1 worktree で衝突ゼロ。実際に使っている構成をそのまま紹介。

  • 複数の Claude Code セッションを見失わずに管理する方法

    worktree・tmux・ターミナルレイアウトを比較し、対応が必要なセッションを即座に見分ける方法。

  • Claude Code の実践的な tmux ワークフロー

    セッションごとに名前付きウィンドウを分け、SSH 切断を乗り越える運用。

対応が必要な瞬間を見逃さない

  • macOS で Claude Code の通知を受け取る方法

    ターミナル通知・ベル音・hook 経由の通知まで、コピペで使える設定をまとめて紹介。

  • hook で Claude Code のセッション状態を追跡する

    hook イベントから waiting / running / done の状態を組み立てる方法とその落とし穴。

セッションごとに 1 つのランプ

AgentManager は実行中の Claude Code セッションを 1 つのフローティングウィンドウにまとめ、 対応が必要なセッションを一目で示します。無料・アカウント登録不要。
