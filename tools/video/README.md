# サービス紹介動画（ヒーロー用 30 秒ループ）

`intro.html` が動画の原稿（HTML/CSS/JS アニメーション）、`render.mjs` がそれを 1 フレームずつ描画して
WebM / MP4 / ポスター画像に書き出すスクリプト。実機収録ではなく合成なので、文言や UI が変わっても
再レンダーで追従できる。

## 動画の設計

- 用途: LP ヒーローの静止スクショの置き換え。無音・自動再生・ループ前提（音の代わりに字幕で説明する）。
- 尺: 50 秒。解像度 1200×960（5:4）。ヒーローでは見出しの下に最大 860px 幅で置く。
- 言語: `?lang=en` / `?lang=ja` で字幕・アウトロを切り替える。ターミナル内の Claude Code 出力は英語固定。
- トーン: 企業の説明動画に寄せる。文はですます調の 1 文。断片的なキャッチコピーにしない。
- 構成: 冒頭 3 枚の中央カード（並行開発していると → 待ちに気付かないこと、ありませんか？ → そんなあなたに、ロゴ）
  で課題から製品へつなぎ、以降は「UI 上で何かが起きる → 下段のナレーションで説明」を 5〜7 秒ずつ。
- ナレーション: 画面下のパネルに出し、シーンを暗転させずに動きと同時に読めるようにする。1 枚 3.5〜4.5 秒。
- 注目誘導: スポットライト（説明対象だけ明るく残し、周囲を少し暗くする）。待っている窓、メニューバーとウィンドウ、
  ジャンプ先の窓、の順に移動する。
- 複数走らせている感: ターミナル 4 枚をカスケードで並べ、待っている 1 枚以外はスピナーが回り続ける。
- 待たせている感: 承認プロンプトが出た瞬間、その窓のタイトルに「● 入力待ちです」が出て枠がゆっくり脈打ち、
  Dock のターミナルアイコンが跳ねてバッジが付く（macOS のベル挙動）。誰も気づかず時計だけが進む。
- 構成（秒）:

## 書き出し

```sh
# playwright（chromium 同梱）と、libvpx / libx264 入りの ffmpeg が必要
PLAYWRIGHT_MODULE=$(npm root -g)/playwright FFMPEG=/path/to/ffmpeg \
  node tools/video/render.mjs --lang ja --out /tmp/intro-out
```

- `--sheet` を付けると 13 枚のキーフレームだけを描画し、`sheet-<lang>.png` に並べる（構図確認用、数秒で終わる）。
- フル書き出しは 30fps × 尺ぶんのスクリーンショット → `intro-<lang>.webm`（VP8）と `intro-<lang>.mp4`（H.264）、
  `intro-poster-<lang>.jpg`（通知カットの静止画。ページのポスター画像）を生成する。libx264 がない ffmpeg では
  MP4 だけスキップされる。
- ブラウザで `intro.html?lang=ja` を直接開くとループ再生でプレビューできる。`&capture=1` を付けると自動再生せず、
  `window.seek(秒)` で任意の時刻に止められる。

## LP への配置

- リポジトリ直下の `intro-en.mp4` / `intro-ja.mp4` / `intro-poster-en.jpg` / `intro-poster-ja.jpg` がページで使う実体。
  書き出し先から英日ぶんをコピーして置き換える（WebM は配布しない。対象が macOS なので MP4 で全ブラウザ再生できる）。
- ヒーローの `<video>` は `index.html` に 1 つだけ書き、日本語版の `src` / `poster` / `aria-label` は
  `data-ja-*` 属性に書く。`tools/gen-ja.py` が `ja.html` 生成時に属性を差し替える。
- 再生は無音・自動再生・ループ。クリックで一時停止と再開、下端の細いバーでシーク（ドラッグ、← → キー）、
  画面外にスクロールしたら一時停止する。

## 編集のしかた

- 文言（カード・ナレーション・タグライン・状態名）は `intro.html` 冒頭の `STR` にまとめてある。日本語の
  ナレーションは `<br>` で改行位置を指定する（パネル内で語の途中で折り返さないため）。
- 中央カードの区間は `CARDS`、ナレーションの区間は `SUBS`、スポットライトの対象は `WAIT_RECT` / `AM_RECT`。プロンプトが現れる時刻は `PROMPT_AT`。尺は `DURATION`（書き出しスクリプトは
  ページから読む）。カット境界をずらすときはこれらと `seek(t)` 内の各 `prog(t, 開始, 終了)` を合わせて動かす
  （タイムラインの一覧は `seek` 直前のコメント）。
- ターミナル 4 枚の位置・本文は `TERMS`、AgentManager の行は `SESSIONS`、各カットでの状態は `seek(t)` 内の `rowState`。
